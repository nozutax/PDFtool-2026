# PDF Tools (GAS) 2026

Google Apps Script Web アプリ版の PDF Tools です。  
**利用者自身の Google アカウントのマイドライブ**から PDF / JPEG を選択できます（`executeAs: USER_ACCESSING`）。

## 機能

- 分割 / 結合 / 整理(削除) / 圧縮
- ファイル追加: 「＋」メニュー → Google Drive / ローカル Upload / DnD
- Drive はパンくず付きフォルダブラウザ（PDF・JPEG）

## 静的版との違い

GitHub Pages 版（`PDFtool-2026`）はローカル Upload のみです。Drive 連携はこの GAS 版のみ。
